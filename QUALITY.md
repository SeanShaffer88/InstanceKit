# InstanceKit — Quality Scorecard

Scored under The Elite Software Master Prompt v1.1, §17. Every score names its evidence; a score without evidence would be a Fail. This file is updated in the same change as the work it scores.

**State at v0.1.0: total 86.2/100 — the release bar (total ≥ 85, no dimension below 3, no Fail) is met for the local gate.** Two recorded waivers remain (Performance and Scalability measurements), and Windows runtime behaviour is Partially Verified: CI's real MSVC build is the link gate, and an on-machine field pass has not yet run. **The Win32 backend (mutex election, overlapped pipe listener, ack-bounded forward) is Unverified at runtime**: it compiles and clippy/checks clean for `x86_64-pc-windows-msvc` in the local gate, and every pure half it feeds (frame codec, envelope, state machine, mailbox) is unit-tested on Linux, but no Windows machine has executed it yet.

## What moves the score

1. On-machine Windows field pass — two real processes, forward + ack timing, primary killed mid-forward, `global` scope across sessions, release → re-acquire (raises Correctness and Robustness; anything found is fixed forward with a regression test).
2. A recorded forward round-trip latency figure and a secondary-burst exercise (closes both waivers in one field session).
3. Coverage measurement, or recording test-count evidence as the accepted substitute (closes the Test evidence note).
